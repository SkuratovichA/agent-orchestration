# Language servers

Builders, reviewers and the reader navigate with the `LSP` tool; builders also treat the diagnostics that arrive after an edit as their first gate, which is why `builder-m` at `medium` is enough for most work. A server's first answer after it starts can be short, so every agent asks for a list of references twice before anything is decided on it. A language server needs its plugin enabled and its binary on PATH. `references/language-servers.tsv` at the plugin root lists, per project marker file, the language, the plugin, the binary and the install command. The plugin's SessionStart check (`hooks/lsp-check.sh`) adds one line to the session when a marker file sits in the working directory or up to two levels below it and the binary is missing; it never installs anything, and it says nothing about a server whose plugin is switched off in the settings. When that line appears, tell the user before the first builder spawn and install only on their go-ahead.
